📚 Library Management System

My first Python project — a simple library management system built using Python.

🚀 Features

- Add Books: Add new books to the library.
- Display Books: View all books in the library.
- Borrow Books: Borrow available books and update their status.
- Return Books: Return borrowed books and make them available again.

🛠️ Technologies Used

- Python
- Dictionaries
- Loops
- Conditional Statements
- User Input and Output

🎯 Project Goal

This project was created to practice Python fundamentals and apply programming logic to a practical application.
